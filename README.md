# brsrk.s

Небольшой сборщик колод для ККИ Берсерк.

## Структура

- `main.py` — точка входа приложения
- `ui/` — Qt-интерфейс: основное окно и draft-режим
- `domain/` — модели карт и правила фильтрации/сортировки
- `services/` — сохранение колод и расчёт статистики
- `repositories/` — граница между интерфейсом и базой данных
- `data/cards.db` — локальная база карт
- `app_theme.py` — общие цвета, размеры и стили
- `repositories/db_manager.py` — низкоуровневая работа с `data/cards.db`
- `domain/card.py` — dataclass-модель карты
- `services/deck_image_export.py` — генерация изображения колоды
- `services/image_paths.py` — поиск изображений из локальной папки проекта
- каталог использует фиксированный размер ячейки и меняет только число столбцов при изменении окна
- `tools/generate_placeholder_images.py` — создание изображений-заглушек
- `decks/` — пользовательские JSON-колоды

```text
berserc_app/
├── main.py
├── ui/
│   ├── main_window.py
│   └── draft_window.py
├── domain/
├── services/
├── repositories/
├── tests/
├── data/
└── decks/
```

## Запуск

Установите зависимости из `requirements.txt` и запустите `main.py` из корня проекта. База данных берётся из папки проекта, поэтому приложение можно запускать из любой рабочей директории.

## Возможности

- просмотр каталога карт
- поиск, сортировка и фильтры
- сборка и сохранение колод
- проверка наличия карт
- режим draft
- генерация изображения колоды
